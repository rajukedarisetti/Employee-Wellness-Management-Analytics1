# Employee Mood Mentor

## Employee Wellness Management Platform

### Project Objective

Develop an AI-powered Employee Wellness Management platform that promotes workplace well-being through intelligent mental health monitoring, mood tracking, wellness analytics, and personalized recommendations. The application provides secure user authentication and helps organizations monitor employee wellness effectively.

---

## Technologies Used

- Python
- Streamlit
- HTML
- CSS
- JavaScript
- PostgreSQL / SQLite
- JWT (JSON Web Token)
- Google SMTP (Email OTP)
- Hugging Face Spaces
- Git & GitHub

---

## Features

- User Registration
- Email OTP Verification
- Secure Login
- Forgot Password with Email Verification
- Employee Wellness Dashboard
- Employee Mood Tracking
- AI-Based Wellness Insights
- Employee Wellness Analytics
- Personalized Wellness Recommendations
- Secure Session Management
