# 🩺 Employee Mood Mentor

An AI-powered Employee Wellness Management platform designed to promote workplace well-being through intelligent mental health monitoring, sentiment analysis, and personalized wellness support.

## 📌 Project Overview

Employee Mood Mentor is a web application that helps organizations monitor and improve employee wellness. The platform provides secure authentication, employee mood tracking, wellness analytics, and AI-driven recommendations to support a healthier work environment.

---

## 🎯 Features

- 🔐 Secure User Registration
- 📧 Email OTP Verification
- 🔑 Secure Login System
- 🔒 Forgot Password with Email Verification
- 📊 Employee Wellness Dashboard
- 😊 Mood Tracking
- 🧠 AI-Based Wellness Insights
- 📈 Employee Wellness Analytics
- 🌿 User-Friendly Interface
